# 안전지수 파트

## 담당 기능
공공데이터를 활용하여 위치별 안전지수를 계산한다.
계산 결과를 바탕으로 A~E 안전등급을 부여한다.
히트맵 및 경로추천에 사용할 데이터를 생성한다

## 사용 예정 데이터
- CCTV 위치 데이터
- 가로등 위치 데이터
- 경찰서/지구대 위치 데이터
- 사고 또는 위험 관련 데이터

## 산출물
- 위치별 안전점수 CSV
- A~E 안전등급
- 히트맵 및 경로추천에서 사용할 데이터

## 계산 방식 초안
반경 1km 이내의 안전시설 개수와 위험요소를 기준으로 안전점수를 계산한다.
CCTV, 가로등, 경찰시설은 점수를 높이는 요소로 반영한다.
사고, 위험 관련 데이터는 점수를 낮추는 요소로 반영한다.
